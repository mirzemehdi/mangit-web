How the hybrid works

  1. Find the bubbles without a model

    A few milliseconds of image analysis find enclosed light regions with ink inside, their shape and which way the text runs. No AI call, nothing sent.

  2. Gemini Nano reads the easy ones

    Each bubble is cropped small and read on your computer through Firebase AI Logic. Horizontal text, Korean and Chinese, works well on-device.

  3. The cloud takes the hard ones, in parallel

    Vertical Japanese is Nano's weak spot, so those bubbles go straight to Gemini in the cloud while Nano keeps reading. Bubbles Nano is unsure about get a second opinion.

  4. Names stay consistent

    Character names you add are shared per series through Firestore and used by both models, so every reader of a series sees the same spelling.

Use it on any page

The Chrome extension adds a side panel that translates the page you're reading, with the same hybrid engine.

  1. Download the latest mangit-lens.zip and unzip it.
  2. Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder.
  3. Open a manga page, click the Mangit Lens icon and press Translate this page (or Alt+T).

Privacy: Mangit Lens counts anonymous totals (pages, modes, how many bubbles stayed on your computer) to show how it's used. No images, text, page addresses or names are ever stored.

Reading on your phone? Mangit translates whole chapters with cleaned art on iOS and Android.

Mangit Lens is open source (Apache 2.0). Built with Firebase AI Logic hybrid inference for #BuildHybridAI.
